基于C++、OpenCV和YOLOv8实现的多目标跟踪系统。

项目简介：本项目基于YOLOv8实现目标检测，并结合IoU、目标中心距离和卡尔曼滤波器实现多目标跟踪。系统可以对摄像头中的多个目标进行检测、匹配和持续跟踪，并为每个目标分配独立ID。

项目主要功能：

YOLOv8目标检测
人员目标筛选
多目标ID分配
IoU 匹配
中心距离匹配
IoU + 中心距离联合匹配
卡尔曼滤波器目标预测
目标损失处理
目标运动方向判断
目标像素速度计算
目标运动食谱显示
人数统计
追踪数量统计
CSV 数据记录
CUDA GPU 加速
